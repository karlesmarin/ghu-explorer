What this tool is for

The guide index groups tools by scientific family and lets you search by task, input or result. Every menu section has a short How to use panel with a direct link here. Experiments inside a section and the three Simulator modes also have their own guides. English and Spanish pages describe the same tools; English control labels remain recognizable in both languages.

First steps

  1. Choose a task in the guide index or select a family in the application menu.
  2. Start from a reference or preset before changing one input at a time.
  3. Read the units, assumptions and result status with the plot.
  4. Save the inputs and source record with any result you want to compare or share.

Reading the results

ResultMeaning
Calculated value or numerical checkA result within the implemented model and numerical settings; convergence tests address their stated numerical question.
Certificate or formal theoremA machine-checked or rigorously bounded statement with explicit hypotheses. It does not certify the full physical model.
Experimental comparisonUses a named dataset and hypothesis. A reference overlay, range check and statistical likelihood are not interchangeable.
Unknown, unresolved or not evaluatedA boundary of the calculation. It must not be converted into an allowed, excluded or impossible conclusion.

The laboratory contains several distinct models. A green check, a converged sum, a formal theorem and agreement with an experimental reference each establish different things. Always retain the stated assumptions.

Worked example

A first 5D workflow

  1. Open SU(N) builder and load a supported reference.
  2. Inspect the potential and its located vacuum.
  3. Continue to KK spectrum, then the anomaly audit.
  4. Inspect brane filtering if the reference requires it.
  5. Use Simulator to read scale calibration and dimensionful outputs.
  6. Save the complete model record before exploring another input.

What to expect: Each step answers a different question. Passing one check does not replace the next or establish complete phenomenological viability.

Scope and limitations

  • Separate SU(7), SU(4), flat 5D, warped, thermal and neutrino-ring models must not be combined without a defined matching calculation.
  • A finite scan does not establish nonexistence outside its stated domain.
  • The current guides describe the current instrument; archived HTML editions and videos retain their own dates and scope.
  • The self-contained application keeps its short help offline. Full web guides and external references require access to their files or websites.

If something is unclear

The guide opens a different-looking part of the Simulator.

Check the model selector: builder, neutrino ring and Higgs production are distinct modes.

A changed input gives no new valid result.

Read the validation message. Some panels retain the last valid result until the input is corrected.

You cannot find a calculation.

Search the guide index, including embedded experiments, or use the related guides at the end of a page.
