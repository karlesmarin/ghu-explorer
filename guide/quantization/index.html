What this tool is for

Use this independent diagnostic before interpreting a polynomial cancellation as a globally quantized action. The global quotient correlates apparently separate coefficients. Closed spin-four periods ask a different question from universal degree-four cohomology. The panel makes this distinction visible and supplies exact witnesses rather than a single undifferentiated consistency label.

First steps

  1. Run the Demo, then compare C/2, C/36 and A+B.
  2. Enter exact fractions. Inspect the detecting cocharacter or spin manifold when a criterion fails.
  3. Change integer tensor pairings and inspect the unchanged residue class.
  4. Export JSON and open the certificate catalogue to replay the appropriate Lean or numerical check.

Passing a restricted arithmetic criterion does not establish a global action or a complete anomaly-free model. The modulo-three response class is conditional; it is not an identified global Z3 anomaly.

Worked example

Same polynomial, different background test

  1. Choose C/2 and read both rows.
  2. Universal integrality fails at the cocharacter (1,0,−1,0,0).
  3. Closed spin-four periods pass because the Y² period is even.

What to expect: These outcomes are compatible: the tests quantify over different backgrounds. Neither determines the orbifold background category.

Formulas and conventions

Change from centered roots to integral characteristic classes.

Universal: α, β, δ integral; closed spin-4: α, β, 2δ integral

Ordinary bundles, with Wu parity supplying the spin restriction externally to Lean.

18K₂ + 24K₃ + K₁ = 0 mod 36

Known q=6 axion criterion; no identification with the GHU Higgs.

6ℓ(v) = 16 − 3p − 3q − 6r = 1 mod 3

Integer obstruction under fixed spectrum and ordinary parent responses.

Q(m,n) = b₀(m−n)²/4 + b₁(m+n)²/8

Joint integrality iff b₀ is integral and b₁+2b₀ is divisible by eight.

tₐ² = −1; Uₐ = −i tₐ; Uₐ² = +1

Representation involution differs from an ordinary Spin(20) isotropy lift.

Scope and limitations

  • The global action on all fields, including bosonic Omega, and the admissible orbifold bundles remain open.
  • The wall SU(2) divisibility criterion is known. No claim of new mathematics or full anomaly cancellation is made.
  • Lean formalizes arithmetic. Characteristic-class topology, Wu parity and physical translations are external assumptions. The 3290 lift checks are exact computational checks, not Lean theorems.
  • The 81 cocharacters are a finite visualization, not a universal proof. Values outside the lattice window are explicitly reported; only pixel coordinates are approximate.

If something is unclear

The input is rejected.

Use an integer or n/d with nonzero positive denominator. Tensor, axion and U(2) controls require integers. The last valid state is retained.

The result passes but model consistency is not checked.

Read the scope: a restricted quantization criterion is one necessary ingredient of a full action, not a certification of the remaining ingredients.
